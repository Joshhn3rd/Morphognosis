Plant Prediction

Enter this week's conditions and your plant's previous structure to forecast its next weekly growth.

How the prediction is made

The next week's plant structure Pn (height, leaves and branches) starts from last week's structure and adds growth from this week's water, temperature and sunlight.

Pn = [ Hn Ln Bn ] = f ( [ Hn−1 Ln−1 Bn−1 ] + [ {% for r in [("H","H"),("L","L"),("B","B")] %} b{{ r[0] }}+ α{{ r[0] }}Wn+ β{{ r[0] }}Tn+ γ{{ r[0] }}Sn {% endfor %} ] )

fThe hybrid step: the formula's result is averaged with the XGBoost model's estimate (which uses sunlight, temperature, water and the week), then rounded

Values used by the formula

Each input is first divided by a reference value: W ÷ {{ "%g"|format(ref_water) }} mL, T ÷ {{ "%g"|format(ref_temperature) }} °C, S ÷ {{ "%g"|format(ref_sunlight) }} hours. The growth score is then multiplied by the scale and added to last week's value.
